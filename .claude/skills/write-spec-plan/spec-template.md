## 1. 해결하려는 문제

이 기능이 없어서 지금 **무엇이 막히는가**. 사실과 가정을 나눠 쓴다.

- **지금 상태**: (누가 무엇을 하려는데 어떻게 막히는가. 가능하면 실제로 겪은 장면 한 가지)
- **근거**: (QA 결과, 사용자 말, 측정값. 없으면 `[가정]`이라고 쓴다)
- **막혀서 생기는 일**: (시간 낭비, 재실험, 데이터 손실 등)
- **PRD 목표와의 연결**: (KR1~KR4 중 무엇을 움직이는가. 해당 없으면 "해당 없음")
