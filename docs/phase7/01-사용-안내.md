# lablog 사용 안내 (1페이지)

## 가장 먼저 알아 둘 것

**기록은 이 브라우저에만 저장됩니다.** 서버로 보내지 않습니다. 그래서 다음 경우에 기록이 보이지 않습니다.
- 브라우저의 사이트 데이터를 지웠을 때
- 다른 브라우저, 다른 PC, 다른 기기로 열었을 때
- **다른 주소로 열었을 때** (같은 앱이어도 주소가 다르면 저장 공간이 따로입니다)
- 사생활 보호(시크릿) 창에서 썼을 때

**백업 방법**: 설정 → "백업 파일로 내보내기". 날짜가 붙은 JSON 파일이 내려받아집니다. 주 1회 이상, 중요한 실험 직후에 내려받아 두세요. 홈 화면이 백업이 오래됐다고 알려 줍니다.
**복원 방법**: 설정 → "백업 파일 가져오기" → 미리보기를 보고 합치기 또는 바꾸기를 고릅니다. 바꾸기 전에는 현재 데이터를 먼저 자동으로 내려받습니다.
**기기나 주소를 옮길 때**: 옛 쪽에서 내보내기 → 새 쪽에서 가져오기.

## 하루 사용 흐름

1. **새 실험**: 제목을 넣고, 절차를 한 줄씩 붙여 넣거나 입력합니다. 이전 실험이나 템플릿에서 시작하면 절차와 조건이 그대로 따라옵니다.
2. **수행 모드**: 단계를 눌러 체크하고 단계마다 메모와 조건·결과 값을 적습니다. 새로고침해도 입력은 남습니다.
3. **완료**: 비어 있는 결과나 체크하지 않은 단계가 있으면 알려 줍니다.
4. **찾기**: 위쪽 검색창(Ctrl+K). 제목, 단계, 조건, 결과를 함께 찾고 띄어쓰기가 달라도 찾습니다.
5. **프로젝트**: 프로젝트별 진행 현황, 빠진 것 목록, 조건과 결과의 표·차트, 이상치 후보, CSV 내보내기.

## 지운 것을 되살리려면

삭제한 실험은 휴지통에서 30일 동안 복원할 수 있습니다.

## 문제가 생기면

- "화면을 그리는 중 문제가 생겼습니다": 새로고침하세요. 계속되면 설정에서 데이터를 내보낸 뒤 알려 주세요. 설정의 "오류 기록"에 원인이 남습니다.
- "지금 입력하는 내용은 남지 않습니다": 사생활 보호 모드이거나 사이트 데이터가 차단된 상태입니다. 일반 창에서 여세요.
- 사용 기록(검색 시간, 빠진 것 개수)은 이 기기에만 남고 어디로도 전송되지 않습니다. 설정에서 끄거나 지울 수 있습니다.
