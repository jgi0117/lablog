- **환경**: Windows 11, Node 24, Vitest 5, Playwright 1.64(Chromium·Firefox·WebKit), Supabase `lablog-v2`(서울, ref `wqemjezcdakwrjuztdlt`). 브라우저 화면 눈 확인은 하지 못함.

## D. QA 주의사항
- lablog(`../lab`, `main`)의 운영 데이터는 건드리지 않는다. 가져오기는 읽기만 하고 원본을 지우지 않는다.
- 서버 시험(`test:supabase`)은 v2 프로젝트에서만, 데이터가 없을 때만 돌린다.
- 비밀번호·키는 대화에 적지 않는다. 직접 입력한다.
- 실패 시 화면 캡처와 시각(분 단위)을 이슈에 적어 주면 서버 로그를 바로 찾을 수 있다.
- 개발 서버가 이미 떠 있으면 `.env.local` 변경이 반영되지 않는다. 다시 시작한다.
