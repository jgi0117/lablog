## 남은 직접 확인

1. 실제 사용자가 프로젝트에서 준비 실험 저장을 30초 안에 끝낼 수 있는지 측정한다.
2. 실제 사용자가 최근 실험 10건의 핵심 정보를 10초 안에 파악하는지 측정한다.
3. 가능하면 실제 태블릿과 장갑 착용 상태에서 수행 모드 조작을 확인한다.

자동화 환경에서는 위 흐름과 1194×834·810px·390px 레이아웃, 44px 터치 기준이 모두 통과했다. 사용성 시간 기준은 사람의 판단이 필요하므로 자동 결과로 대체하지 않는다.
