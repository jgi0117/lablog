# Phase 8 완료 기록: 복제·템플릿·달라진 점

상태: **1~2번(복제+템플릿, 달라진 점 기록) 구현 완료.** 3번(엑셀·텍스트 가져오기)과 4번(팀 대시보드)은 하지 않았다.

## 만든 것

**복제 (Journey 3 Step 1)**
- 실험 개요의 "복제하여 새 실험" 한 번으로 만들고 새 실험을 연다. 절차와 조건 값은 그대로, 체크·메모·결과 값은 비운다("결과 값과 체크·메모는 비워졌습니다" 안내, E1). 결과 항목은 이름과 단위만 남아 빈 칸으로 보이므로 빠뜨리기 어렵다. 원본은 바뀌지 않고, 달라진 점 기록도 가져가지 않는다.

**템플릿**
- 개요의 "템플릿으로 저장"(이름만 입력)으로 만든다. 절차, 조건 값, 결과 항목 이름·단위만 담고 체크·메모·결과 값은 담지 않는다.
- 템플릿 화면(`/templates`): 목록, 새로 만들기, 편집(이름, 절차를 한 줄에 하나, 조건 `이름 | 값 | 단위`, 결과 항목 `이름 | 단위`), 삭제, "이 템플릿으로 새 실험".
- 새 실험 화면에 "템플릿에서 시작"이 생겼다(`?template=` 주소도 지원). 템플릿을 고르면 "마지막 실험 이어받기"는 숨긴다.

**달라진 점 (Journey 3 Step 3, 편차)**
- 실험 상세에 "달라진 점 (n)" 탭: 목록, 지우기, 입력. "달라진 내용"만 있으면 기록되고, 사유와 대상 단계(기본: 실험 전체)는 선택이다.
- **수행 모드 옆 패널**: "+ 달라진 점 기록" 한 번이면 입력칸이 열리고 포커스가 바로 간다. 지금 보고 있는 단계가 대상으로 미리 골라져 있다. 입력하고 "기록"(또는 Ctrl+Enter)이면 끝나서 탭 2번 이내다. 이미 적은 것은 패널 아래에 보인다.

**데이터와 백업**
- DB v3: `templates`, `deviations` 표 추가(기존 데이터는 그대로, v2에서 올라가는 마이그레이션 테스트 있음).
- 저장소 계약에 `TemplateRepository`, `DeviationRepository`가 생겼고, Supabase 구현(Phase 9)도 같은 계약 테스트를 통과해야 한다.
- 백업 파일 형식을 2로 올렸다. 템플릿과 달라진 점이 들어가고, **버전 1 파일도 가져올 수 있다**(목록이 없으면 빈 목록). 버전 1 파일로 "바꾸기"를 해도 템플릿은 지우지 않는다. 가져오기 검사는 템플릿 이름, 실험이 없는 달라진 점, 중복 id를 거부한다.
- 영구 삭제하면 딸린 달라진 점도 함께 삭제된다. 사용 기록에 `duplicate`, `template_save`, `template_start`, `deviation_add`가 추가되어 복제 사용률 같은 측정이 가능하다.

## 확인한 결과

- `npm run check`: 단위 테스트 257개 통과(계약 테스트, 마이그레이션, 템플릿·달라진 점·복제 화면 14건, 백업 검사 포함).
- E2E(Chromium, Firefox, WebKit): 92개 통과, 10개 건너뜀(이유는 Phase 6 기록과 같음), 실패 0. Journey 3 전체(복제 → 수행 중 달라진 점 → 템플릿 저장 → 템플릿으로 새 실험)와 백업 왕복(다른 브라우저 복원)을 포함한다.

## 남은 것

- 3번 엑셀·텍스트 붙여넣기 가져오기, 4번 팀 대시보드(Supabase 이후).
- 달라진 점 입력이 "2탭 이내"인지는 실제 태블릿에서 장갑을 끼고 확인해야 한다(Phase 6 실기기 확인 목록에 합친다).
- 템플릿 편집은 글자 입력(한 줄에 하나) 방식이라 거친 편이다. 직접 써 보며 불편하면 개선한다.
