## User Journey 요약

**문제**: 실험 기록이 여러 곳에 흩어져 찾기도 재현하기도 어려운 문제

감정과 페인포인트는 [가정]이며 인터뷰로 보정이 필요합니다.

**Journey 1. 새 실험 수행 (s1 모으기)**
- 목표: 단계를 놓치지 않고 진행하면서 바로 기록한다
- 흐름: 새 실험 만들기 → 수행 모드에서 체크·메모 → 결과 입력 후 완료
- 감정: 😐 → 😟 놓칠까 불안 → 😌 체크할 때마다 안심
- 오류: 네트워크 끊김(임시 저장 후 자동 동기화), 실수로 체크(5초 되돌리기), 단계 건너뜀(완료 때 경고)
- 성공 지표: 입력 후 재입력 없이 완료한 비율

**Journey 2. 지난 실험 찾기 (s2 찾기)**
- 목표: 비슷한 지난 실험을 빨리 찾는다
- 흐름: 전역 검색 → 하이라이트 확인 → 필터로 좁혀 열기
- 감정: 😤 어디 적었더라 → 😌 바로 나옴
- 오류: 결과 없음(철자 제안, 필터 해제, 새 실험 안내), 실수로 삭제(30일 복원)
- 성공 지표: 검색 후 10초 이내에 열기

**Journey 3. 복제하여 다시 쓰기 (s3 다시 쓰기)**
- 목표: 선배의 실험을 같은 조건으로 따라 한다
- 흐름: 복제(결과 비움) → 수행 모드 → 달라진 점 기록
- 감정: 😊 처음부터 안 써도 됨 → 😟 → 🙂
- 오류: 복제 후 이전 결과가 남음(자동 비움 + 안내)
- 성공 지표: 선배 도움 없이 수행한 비율

**Journey 4. 프로젝트 살펴보기 (s4 살펴보기)**
- 목표: 맡은 프로젝트에서 빠뜨린 게 없는지 확인하고 결과의 흐름을 한눈에 본다
- 흐름: 홈의 놓친 것 → 프로젝트 현황의 빠진 것 채우기 → 데이터 표·CSV → 분석(관계·추세·이상치)
- 감정: 😟 뭘 빠뜨렸지 → 😌 한 줄로 알려 줌 → 😮 엑셀에 안 옮겨도 됨
- 오류: 이상치가 실제 결과(후보일 뿐, 실험으로 이동해 확인), 단위 섞임("단위 확인" 표시), 이름이 달라 열이 갈라짐(자동 완성)
- 성공 지표: 빠진 것 건수의 주별 감소

**감정 최저점**: 수행과 이상 대응. 수행 중 입력 부담을 줄이는 것이 가장 큰 기회입니다.

**검증**: 연구원 3~5명 인터뷰·실험대 관찰, 실험 중 기기 입력 가능 여부, 최근 실험 3건 찾기 과제
