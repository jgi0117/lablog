## User Journey 요약

**Journey 1. 편리한 실험 등록**
- 프로젝트·제목만 먼저 확인
- 빈 실험 / 마지막 실험 / 기존 실험 선택
- 이어받을 항목을 확인하고 달라진 부분만 수정
- 준비 저장 / 절차 입력 / 바로 수행 선택

**Journey 2. 기록 한눈에 파악**
- 목록에서 목적·상태·진행·주요 조건·결과·편차 확인
- 필요한 실험만 열어 개요에서 누락과 다음 행동 확인
- 별도 검색 없이 목록 필터 사용

**Journey 3. 이전 실험 이어받기**
- 원본 선택 → 포함 항목 확인 → 결과 값·체크·메모 초기화 → 차이만 입력

**Journey 4. 프로젝트 검토**
- 진행 중 실험 → 최근 완료 결과 비교 → 빠진 기록 수정 → 후속 실험 시작

**Journey 5~7**
- 수행 중 즉시 기록과 오류 복구
- 프로젝트 데이터 비교·내보내기
- 로그인·백업·이전과 기존 데이터 보존

**직접 검증**: 최초 저장 시간, 반복 입력 항목 수, 최근 10건 파악 시간, 실험대 터치 조작.
