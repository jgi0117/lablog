## 개발 계획 요약

**현재 상태**
- 구조 재구성 001의 1단계(기준선·린터 경고)는 완료했다.
- 제품 방향 변경으로 001의 2~5단계는 보류한다.
- 핵심 프로젝트·실험 경험 spec 002가 사용자 확정 대기다.

**다음 순서**
1. spec 002 확인 필요 사항 확정
2. plan 002 작성·사용자 확인
3. 편리한 실험 등록과 한눈에 보는 목록·개요 구현
4. 검색·템플릿 UI 제거, 기존 데이터·백업 보존
5. 사용자 여정·회귀·직접 QA
6. 축소된 제품 범위로 구조 재구성 001 재계획

- 새 라이브러리 없음

- 기존 데이터와 템플릿 백업 삭제 금지
