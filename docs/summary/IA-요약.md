## IA 요약

**주 메뉴**: 홈 · 프로젝트 · 실험 · 데이터

**핵심 화면**
- 홈: 진행 중 → 빠진 기록 → 최근 실험
- 프로젝트: 새 실험 → 진행 중 → 최근 완료의 주요 조건·결과 → 빠진 기록 → 데이터·분석
- 실험 목록: 키워드·프로젝트·상태·기간 필터 → 주요 조건·결과가 포함된 요약 행
- 새 실험: 프로젝트·제목 → 시작 방법 → 이어받기 확인 → 달라진 부분 → 다음 행동
- 실험 개요: 목적·진행 → 주요 조건·결과 → 편차·누락 → 다음 행동
- 수행 모드: 현재 단계 → 메모·수치 → 진행률 → 편차

**제거**
- `/search`, 전역 검색창
- `/templates`, 새 템플릿 생성·적용
- 기존 주소는 `/experiments`로 안내하고 기존 데이터는 보존

**핵심 흐름**
1. 프로젝트에서 새 실험 시작
2. 프로젝트 자동 선택과 제목 제안
3. 빈 실험 또는 이전 실험 선택
4. 결과 값·체크·메모를 제외하고 필요한 항목만 이어받기
5. 달라진 부분만 수정해 저장·절차·수행으로 이동
