## IA 요약

**문제**: 실험 기록이 여러 곳에 흩어져 찾기도 재현하기도 어려운 문제

**Site Map**
- 홈
  - 프로젝트 (s4): 현황 · 데이터 · 분석
  - 실험 목록 (s2)
    - 실험 만들기 (s1)
    - 실험 상세: 개요 · 절차(수행 모드) · 조건·결과 (s1) / 첨부 (s2) / 편차 기록 (s3)
  - 검색 (s2)
  - 템플릿 (s3)
  - 팀 (s3, 다음 버전)
- 설정

**Navigation**
- 메인 메뉴: 홈 · 프로젝트 · 실험 · 검색 · 템플릿
- 실험 상세 탭: 개요 / 절차 / 조건·결과 / 첨부 / 편차
- 모든 화면 상단: 전역 검색창, + 새 실험

**화면 우선순위**
- 홈: 진행 중 실험 → 놓친 것(모든 프로젝트) → 최근 실험
- 프로젝트 현황: 진행 현황 → 빠진 것 한눈에 → 타임라인 → 최근 실험
- 수행 모드: 현재 단계 체크 → 메모·수치 입력 → 진행률
- 검색 결과: 일치 문구 하이라이트 → 상태·날짜 → 필터

**핵심 흐름**
- s1: + 새 실험 → 수행 모드에서 체크·메모 → 결과 입력 → 완료
- s2: 전역 검색 → 하이라이트 확인 → 실험 열기
- s3: 새 실험에서 프로젝트 선택 → 마지막 실험 이어받기(결과 값 비움) → 수행 모드
- s4: 홈의 놓친 것 → 프로젝트 → 빠진 것 채우기 → 데이터 표·차트로 비교

**용어**: "실험"으로 통일 / 상태는 준비·진행·완료 / "편차"는 "절차와 달라진 점"으로 표기
