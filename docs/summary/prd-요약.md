## PRD 요약

**문제**: 실험 기록이 여러 곳에 흩어져 찾기도 재현하기도 어려운 문제

**요약**: 여러 실험을 함께 하는 연구원이 실험 기록을 한 곳에 모으고, 분류하고, 검색해서 다시 쓰게 돕는 서비스. 단계 누락으로 인한 재실험을 줄인다. [가정]

**배경**
- 기록이 종이 노트, 엑셀, 메모 앱, 메신저에 흩어져 있다. [가정]
- 체크리스트가 여러 앱에 흩어져 못 찾는 문제는 확인됨(일반 사용자). 실험실도 같은지는 미확인.

**목표**: 실험 단위로 모으고 → 분류하고 → 검색·재사용한다.
- KR1. 지난 실험을 10초 안에 연다
- KR2. 단계 누락으로 인한 재실험이 줄어든다 (먼저 현재 수치 측정)
- KR3. 파일럿 팀 80%가 주 1회 이상 쓴다

**세그먼트**: 연구원(주), 신규 입사자. 팀장은 다음 버전.

**가치 제안**
- 연구원: 종이에 적고 나중에 옮기던 것을, 한 곳에서 체크·기록·검색한다.
- 신규 입사자: 선배의 실험을 복제해 같은 조건으로 시작한다.

**핵심 기능**
- s1 모으기 (Must): 실험 만들기, 절차 체크+메모, 조건·결과 입력
- s2 찾기 (Must): 분류(프로젝트·태그·상태), 통합 검색
- s3 다시 쓰기 (다음 버전): 복제·템플릿, 편차 기록, 팀 대시보드

**확인 필요**
- 기록이 실제로 여러 도구에 분산돼 있나 → 연구원 3~5명 인터뷰
- 재실험 원인이 단계 누락인가 → 최근 5건 분류
- 수행 중 기기 입력이 가능한가 → 실험대 관찰
- 외부 클라우드 저장이 가능한가 → 보안 정책 확인

**출시**
- 첫 버전: s1 전체 + s2 (분류·통합 검색)
- 하지 않음: 장비 연동, 시약 재고, 전자서명·규제 대응, 데이터 분석
- 기간: 1주 가정 확인 → 2주 화면 설계 → 3~4주 구현 → 5주 파일럿 → 6주~ s3 결정
