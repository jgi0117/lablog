## PRD 요약

**문제**: 기능은 많지만 실험을 편리하게 등록하고 기록의 핵심을 한눈에 파악하기 어렵다.

**가치**: 이전 실험에서 달라진 것만 기록하면 프로젝트의 진행과 결과가 한눈에 보인다.

**목표**
- 프로젝트에서 제목만 입력해 30초 안에 실험 저장 `[가정]`
- 반복 실험은 절차·조건·결과 항목을 다시 입력하지 않음
- 최근 실험 10건의 상태·주요 조건·결과를 10초 안에 파악 `[가정]`
- 빠진 기록 감소, 기존 데이터·백업·품질 기준 유지

**핵심 기능**
- 프로젝트 자동 선택과 제목 제안
- 빈 실험 / 마지막 실험 / 기존 실험에서 시작
- 결과 값·체크·메모를 제외한 선택적 이어받기
- 주요 조건·결과가 보이는 실험 목록과 개요
- 프로젝트의 진행 중·최근 완료·빠진 기록·후속 실험 진입점
- 실험 목록 안의 키워드·프로젝트·상태·기간 필터

**범위 조정**
- 별도 검색 화면·전역 검색 제거
- 템플릿 화면과 새 템플릿 생성 제거
- 기존 템플릿 데이터와 백업 호환 유지
- 데이터·분석은 유지하되 이번 작업에서 확장하지 않음

**확인 필요**: 결론·다음 행동 필드 추가, 목록 주요 항목 기준, 30초/10초 목표.
