## User Journeys: 실험 기록 서비스

**풀려는 문제**: 실험 기록이 여러 곳에 흩어져 찾기도 재현하기도 어려운 문제

**구성 기준**: s1 모으기 · s2 찾기 · s3 다시 쓰기 · s4 살펴보기

감정과 페인포인트는 [가정]이며, 연구원 인터뷰로 보정이 필요합니다. 화면은 IA.md 기준입니다.

---

### Journey 1: 새 실험 수행 (s1 모으기)

**Overview**
- 우선순위: Critical
- 사용자: 연구원 (3~4개 실험을 병행)
- 빈도: 매일
- 성공 지표: 수행 중 입력 후 재입력 없이 완료한 비율, 단계 누락 건수

**목표**
> "실험 단계를 놓치지 않고 진행하면서 바로 기록하고 싶다. 그래야 나중에 다시 옮겨 적지 않아도 된다."

**전제**
- 로그인한 상태, 실험 대상 프로젝트가 있음
- 실험대에서 장갑을 낀 채 태블릿 또는 PC 사용 [가정]

**Step 1. 새 실험 만들기**
- 사용자 행동: 홈에서 + 새 실험 → 제목·목적·프로젝트 입력
- 시스템 반응: 실험 생성, 절차 탭으로 이동
- 감정: 😐 귀찮지만 해야 함
- 성공 기준: 입력 3번 이내에 생성
- 마찰: 입력 항목이 많으면 이탈 → 필수는 제목만

**Step 2. 수행 모드로 단계 진행**
- 사용자 행동: 단계 체크, 메모·수치 입력
- 시스템 반응: 현재 단계 강조, 진행률 갱신, 저장 표시
- 감정: 😟 놓칠까 불안 → 😌 체크할 때마다 안심
- 성공 기준: 체크와 입력이 한 화면, 입력 후 즉시 저장 표시
- 마찰: 장갑 낀 손으로 누르기 어려움 → 버튼과 체크 영역을 크게

**Step 3. 조건·결과 입력과 완료**
- 사용자 행동: 이름-값-단위로 결과 입력 → 상태 완료
- 시스템 반응: 미완료 단계나 빈 결과가 있으면 목록으로 알림
- 감정: 😮‍💨 → 🙂 이미 정리돼 있음
- 성공 기준: 완료 처리 후 대시보드에 반영
- 마찰: 단위 오입력 → 단위는 선택식

**오류 시나리오**
- **E1 네트워크 끊김**: 입력은 기기에 임시 저장, "저장 대기 중" 표시. 연결되면 자동 동기화.
- **E2 단계를 실수로 체크**: 5초 안에 되돌리기, 체크 해제 가능.
- **E3 단계 건너뜀**: 완료 누를 때 미완료 단계를 보여 주고 돌아가게 함.

**측정**
- 실험 생성→완료까지 걸린 시간, 단계별 이탈, 오류 후 복구율

### Journey 2: 지난 실험 찾기 (s2 찾기)

**Overview**
- 우선순위: Critical
- 사용자: 연구원, 신규 입사자
- 빈도: 주 여러 번
- 성공 지표: 검색 후 10초 이내에 실험 열기

**목표**
> "비슷한 지난 실험을 빨리 찾고 싶다. 그래야 같은 조건을 다시 알아내느라 시간을 쓰지 않는다."

**전제**
- 실험이 여러 건 저장돼 있음, 사무실 PC 또는 실험대 기기

**Step 1. 검색**
- 사용자 행동: 상단 검색창에 키워드나 조건 입력
- 시스템 반응: 제목·단계·조건·결과에서 일치한 결과를 하이라이트와 함께 표시
- 감정: 😤 어디 적었더라 → 😌 바로 나옴
- 성공 기준: 결과가 입력 후 2초 안에 표시
- 마찰: 키워드가 달라 못 찾음 → 철자·유사어 제안

**Step 2. 좁히고 열기**
- 사용자 행동: 프로젝트·태그·기간 필터 → 실험 열기
- 시스템 반응: 실험 상세 표시
- 감정: 🙂
- 성공 기준: 검색에서 상세까지 10초 이내
- 마찰: 결과가 너무 많음 → 필터와 정렬을 결과 위에 고정

**오류 시나리오**
- **E1 결과 없음**: "일치하는 실험이 없습니다" + 필터 해제 버튼 + 새 실험 만들기.
- **E2 실험을 실수로 삭제**: 휴지통에서 30일 안에 복원.

**측정**
- 검색→열기 시간, 검색 후 결과 없음 비율, 필터 사용률

### Journey 3: 복제하여 다시 쓰기 (s3 다시 쓰기)

**Overview**
- 우선순위: High
- 사용자: 신규 입사자, 연구원
- 빈도: 주 1~2회
- 성공 지표: 복제로 시작한 실험 비율, 선배 도움 없이 수행한 비율

**목표**
> "선배가 한 실험을 같은 조건으로 따라 하고 싶다. 그래야 실수 없이 재현할 수 있다."

**전제**
- 복제할 실험이 있음 (검색 또는 템플릿으로 찾음)

**Step 1. 복제**
- 사용자 행동: 실험 상세 → 복제하여 새 실험
- 시스템 반응: 절차·조건은 유지, 결과는 비운 새 실험 생성, "결과는 비워졌습니다" 안내
- 감정: 😊 처음부터 안 써도 됨
- 성공 기준: 클릭 2번 이내
- 마찰: 이전 결과가 남아 있으면 혼동 → 자동으로 비움

**Step 2. 따라 하며 수행**
- 사용자 행동: 수행 모드로 진행, 모르는 곳은 단계 메모에 질문 기록
- 시스템 반응: Journey 1과 같은 수행 화면
- 감정: 😟 → 🙂
- 성공 기준: 단계 메모만으로 선배에게 질문 전달 가능

**Step 3. 달라진 점 기록 (P1)**
- 사용자 행동: 절차와 달라진 점·사유 입력
- 시스템 반응: 편차 탭에 이력 저장
- 감정: 😰 바쁨 → 🙂 두 번 탭으로 끝
- 성공 기준: 입력 2탭 이내

**오류 시나리오**
- **E1 복제 후 이전 결과가 남음**: 복제 시 결과 필드 자동 비움 + 안내.
- **E2 동시 수정 (P2)**: 변경 충돌 알림, 단계 단위로 병합.

**측정**
- 복제 사용률, 편차 기록률, 복제 실험의 완료율

### Journey 4: 프로젝트 살펴보기 (s4 살펴보기)

**Overview**
- 우선순위: Critical (이 서비스의 차별점)
- 사용자: 연구원(사원) — 여러 프로젝트를 병행
- 빈도: 주 1~2회, 실험을 끝낸 날
- 성공 지표: 빠진 것이 주마다 줄어든다, 분석 화면 사용률

**목표**
> "내가 맡은 프로젝트에서 빠뜨린 게 없는지 확인하고, 결과가 어떻게 움직이는지 한눈에 보고 싶다. 그래야 엑셀에 다시 모으지 않고 다음 조건을 정할 수 있다."

**전제**
- 프로젝트에 실험이 여러 건 쌓여 있음, 조건·결과를 같은 이름으로 입력해 왔음

**Step 1. 놓친 것 확인**
- 사용자 행동: 홈의 "놓친 것"을 본다 → 프로젝트를 연다
- 시스템 반응: 심각한 것부터 종류(빈 결과, 이상치 후보, 빠진 항목, 멈춘 실험)와 이유, 해당 실험 링크를 보여 준다
- 감정: 😟 뭘 빠뜨렸지 → 😌 한 줄로 알려 줘서 다행
- 성공 기준: 홈에서 두 번 눌러 해당 실험에 도착
- 마찰: 너무 많이 나오면 무시하게 된다 → 처음 6건만 펼치고 나머지는 접음. 오탐은 파일럿에서 조정

**Step 2. 빠진 것 채우기**
- 사용자 행동: 항목을 눌러 해당 실험으로 가서 결과나 조건을 입력한다
- 시스템 반응: 입력하면 자동 저장, 프로젝트로 돌아오면 목록에서 사라진다
- 감정: 🙂 하나씩 줄어드는 게 보임
- 성공 기준: 채운 항목이 즉시 목록에서 빠진다
- 마찰: 의도적으로 건너뛴 항목도 계속 나온다 → "확인함" 처리가 필요한지 파일럿에서 판단

**Step 3. 데이터 한곳에서 보기**
- 사용자 행동: 데이터 탭에서 실험 × 항목 표를 본다, 필요하면 CSV로 내보낸다
- 시스템 반응: 같은 이름의 조건·결과를 한 열로 모아 보여 주고 이상치(▲)와 빈 값(—)을 표시한다
- 감정: 😮 엑셀에 안 옮겨도 되네
- 성공 기준: 표를 만들기 위해 따로 옮겨 적은 횟수 0
- 마찰: 항목 이름이 다르면 열이 갈라진다 → 입력할 때 같은 프로젝트의 항목을 자동 완성

**Step 4. 관계와 추세 보기**
- 사용자 행동: 분석 탭에서 가로축(조건)과 세로축(결과)을 고른다
- 시스템 반응: 산점도와 상관계수, 한 줄 해석, 실험 순서별 추세, 이상치 후보를 보여 준다. 점을 누르면 그 실험으로 간다
- 감정: 🤔 → 😊 건조 온도를 올리면 밀착성이 떨어지는 경향이 보임
- 성공 기준: 차트에서 실험을 열기까지 두 번 이내
- 마찰: 숫자 값이 3건 미만이면 그릴 수 없다 → 안내 문구로 이유를 알려 줌. 상관이 원인은 아님을 함께 안내

**오류 시나리오**
- **E1 이상치가 실제 결과인 경우**: 후보일 뿐이라고 표시하고 해당 실험으로 바로 가 확인하게 한다.
- **E2 단위가 섞인 항목**: 표 머리글에 "단위 확인"을 붙이고 빠짐 점검에 "단위 불일치"로 알린다.
- **E3 항목 이름이 달라 열이 갈라짐**: 입력 단계에서 자동 완성으로 줄이고, 표에서 열이 따로 보이면 이름을 고치도록 안내.
- **E4 파일을 저장할 수 없음(CSV)**: "파일을 저장하지 못했습니다. 브라우저의 다운로드 설정을 확인하세요."

**측정**
- 빠진 것 건수의 주별 추이, 빠짐 점검에서 실험 열기까지 걸린 시간, 분석 탭 사용 횟수

### 감정 변화 (1=불편, 5=만족)

- 현재: 찾기 2 → 시작 2 → 수행 2 → 이상 대응 1 → 마무리 2 → 재사용 2
- 개선 후: 찾기 4 → 시작 4 → 수행 4 → 이상 대응 4 → 마무리 4 → 재사용 5

최저점은 수행과 이상 대응입니다. 수행 중 입력 부담을 줄이는 것이 가장 큰 기회입니다.

### UX 점검 (공통)

- **명확함**: 지금 단계와 다음 할 일이 보인다
- **속도**: 입력 후 즉시 저장 표시, 검색 2초 이내
- **되돌리기**: 체크·삭제를 되돌릴 수 있다
- **손 상태**: 장갑 낀 손으로 누를 수 있게 큰 버튼 [가정]

### 검증 계획

- 감정 최저점(수행·이상 대응)이 실제인가 → 연구원 3~5명 인터뷰와 실험대 관찰
- 실험 중 기기 입력이 가능한가 → 환경 관찰
- 검색 키워드 패턴 → 최근 실험 3건 찾기 과제
