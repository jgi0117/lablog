이전 단계의 문제 정의(실험 기록이 흩어짐)는 `문제정의-솔루션.md`에 있다.

## 지금(lablog v1)의 상태

사실(코드·QA로 확인):
- 기능은 갖춰졌다: 실험 기록·수행 모드, 조건·결과, 프로젝트·고객 요구 판정, 검색, 템플릿·편차, 휴지통, 백업, 데이터 허브·통계, 서버 저장소(Supabase)와 로그인, 로컬 저장소 모드. 직접 QA 21개 중 19개 Pass, 1개 Fail(두 탭 충돌 안내), 1개 No Run.
- 구조 부채가 있다: 300줄 넘는 파일 9개(`localBackend.ts` 471줄, `SettingsPage.tsx` 466줄 등), 폴더가 계층형(`pages/components/services`)이라 화면과 저장소가 얽힌다, 저장소 구현 두 벌(local, remote)과 시험 두 벌.
- 문서가 앱과 어긋난다: PRD는 통계 모형을 "하지 않음"으로 두었으나 구현은 상관·회귀·분산분석을 포함하고, IA·UJ에 로그인·데이터 허브·이전 화면이 없다.
- 두 탭 동시 수정 때 충돌 안내가 나오지 않은 사례의 원인을 아직 모른다.

## 문제

**기능은 늘었는데 구조와 문서가 따라오지 못해서, 다음 기능을 안전하게 얹거나 고치기 어렵다.** 파일이 크고 계층 경계가 없어 한 곳을 고치면 어디가 깨지는지 알기 어렵고, 기획 문서가 현재 앱과 달라 개발이 문서를 근거로 하지 못한다.

## 목표 (v2)

1. **구조**: 클린 아키텍처(feature-first, 의존 방향은 린터로 강제), 모든 파일 300줄 이하(목표 200줄).
2. **기능 유지**: lablog v1의 기능을 모두 유지한다(로컬 모드 포함). 기존 시험 450개와 E2E 112개가 단계마다 통과한다.
3. **문서 신뢰**: PRD·IA·UJ·ERD·Spec/Plan이 현재 앱과 일치하고 개발의 근거가 된다.
4. **품질**: 두 탭 충돌 같은 서버 저장소 동작을 공용 계약 시험으로 고정한다.

핵심 가치(우선순위 동일): 기록(수행 모드), 분석(데이터 허브·통계·요구 판정), 찾기(검색·재사용).

## 사용자

개인 연구원 1명(파일럿). 데이터는 본인만 본다. 팀 공유는 이번 범위 밖이다(구조는 `owner_id` + RLS로 확장 가능하게 둔다).

## 제약

- 코드는 `lablog-v2`(lablog 복사 사본)의 `v2` 브랜치에서만 바꾼다. `main`과 lablog 폴더는 건드리지 않는다.
- Supabase는 v2 전용 새 프로젝트(`lablog-v2`, 서울, 무료). lablog 운영 DB와 분리한다.
- 기한은 정하지 않는다. 단계별 완료로 진행한다. 새 라이브러리는 되도록 들이지 않는다.
- 디자인은 lablog 디자인 기준(엔틱 노트 톤)을 유지하고, 접근성·반응형·토큰·상태 화면은 전역 규칙을 따른다.

## 성공 기준

- SC-A. 코드 파일이 모두 300줄 이하다(린터가 통과).
- SC-B. `npm run check`와 E2E가 각 단계 끝에 통과한다. 기존 시험은 고치지 않고 통과한다.
- SC-C. import 경계 린터가 위반 0건이다(domain은 프레임워크·저장소를 import하지 않고, 컴포넌트는 data를 직접 import하지 않는다).
- SC-D. 서버 저장소 계약 시험에 "A가 먼저 저장하면 B의 저장은 충돌" 시나리오가 있고 통과한다.
- SC-E. PRD·IA·UJ·ERD가 현재 화면·표와 일치한다(점검표로 확인).
- SC-F. lablog 데이터(실험 1,030건 등)를 v2에 백업 JSON으로 옮기면 건수가 모두 맞는다.
- KR1(검색 10초 안에 열기)과 KR3(빠짐 점검 감소)는 유지한다.

## 열린 질문

1. QA 13번(두 탭 충돌 안내 없음)을 재현한 순서: 사용자가 기억나지 않음(`[모름]`). v2의 계약 시험으로 직접 재현한다.
2. 기관 보안 정책상 외부 클라우드(Supabase 서울) 저장이 가능한가(사용자 확인 필요, 기관 정책).
3. 만든 QA 개선 목록: 없음으로 시작하고, 재구성 중 생기는 개선은 Intent의 열린 질문에 모은다.
4. v2 전용 Vercel 프로젝트는 새 Supabase 연결 값으로 만들고 대시보드 작업이 필요하다(사용자).
