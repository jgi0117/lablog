## 직접 해볼 것

각 항목을 하고 "기대"와 같은지 본다. 다르면 화면을 캡처해 알려 준다.

### 1. 로그인
- [ ] 로그아웃 → 로그인 화면에 "계정 만들기" 버튼이 **없다**.
- [ ] 틀린 비밀번호 → "이메일 또는 비밀번호가 맞지 않습니다".
- [ ] 맞는 비밀번호 → 홈이 열리고 프로젝트 4개가 보인다.
- [ ] 새로고침해도 로그인이 유지된다.

### 2. 데이터가 서버에서 오는지
- [ ] 홈·프로젝트 목록에 스탠다드믹스 SM-00, 에코슬래그 ES-30, 로히트 플라이 LF-20, 하이브리드본드 HB-50이 있고 실험 수가 232 / 334 / 239 / 225다.
- [ ] 데이터 허브에서 전체 1,030건이 보이고 통계·내보내기가 동작한다.
- [ ] 다른 브라우저(또는 시크릿 창)에서 같은 계정으로 로그인해도 같은 데이터가 보인다(로컬 저장소가 아니라는 증거).

### 3. 쓰기가 서버에 저장되는지
- [ ] 새 실험을 만든다 → 담당자 칸에 표시 이름(`jgi0117`)이 미리 들어 있다.
- [ ] 단계 추가, 체크, 조건·결과 값 입력 → 새로고침해도 남는다.
- [ ] 같은 실험을 두 탭에서 열어 한쪽만 고친 뒤 다른 쪽에서 저장 → 충돌 안내가 뜬다.
- [ ] 실험을 삭제 → 휴지통에 보이고 복원된다.
- [ ] 복제, 템플릿 저장·사용, 달라진 점 기록이 된다.

### 4. 프로필·비밀번호
- [ ] 설정 → 표시 이름을 바꾸고 저장 → 새 실험의 담당자에 바뀐 이름이 들어간다.
- [ ] 설정 → 새 비밀번호 6자 이상 → 비밀번호 변경 후 로그아웃·로그인이 새 비밀번호로 된다.

### 5. 서버 쪽 확인 (Supabase 대시보드 → Table Editor)
- [ ] 3번에서 만든 실험이 `experiments` 표에 있고 `assignee`가 표시 이름이다.
- [ ] `profiles` 표에 내 행이 있다.
