# 디자인 기준 (엔틱)

토큰 파일: `app/src/styles/tokens.css`
시안: `design-drafts.html`(같은 폴더)의 엔틱 스타일. 구조 설계는 `wireframes.html`.

## 방향

바랜 종이 위에 잉크로 적은 실험 노트. 장식은 이중 테두리, 로마 숫자, 붉은 밀랍 도장으로 제한하고, 입력과 체크는 크고 분명하게 둔다. 분위기보다 수행 중 가독성과 조작성이 우선이다.

## 색 사용

- 바탕 `paper`, 카드·패널 `paper-raised`, 입력칸 `paper-field`, 진행 막대 바탕 `paper-sunken`
- 글자 `ink`(본문) / `ink-2`(보조) / `ink-3`(힌트, 비활성)
- 선 `rule`
- 청동록 `verdigris`: 완료, 진행 막대, 선택된 필터
- 붉은 밀랍 `wax`: 현재 단계, 주요 버튼(저장·완료·새 실험), 위험 동작
- 황동 `brass`와 가죽 `leather`: 왼쪽 메뉴와 로고만

대비 기준: 글자는 배경 대비 4.5:1 이상, 도형(테두리·체크)은 3:1 이상(WCAG AA). 토큰 조합 26개를 `app/src/styles/contrast.test.ts`가 자동 검사한다. 검사 결과 `ink-3`(#6f5b3c)와 경고색(#8a5f17)은 처음 값이 기준에 못 미쳐 어둡게 조정했다. 토큰 색을 바꾸면 이 테스트가 먼저 알려 준다. 상태는 색만으로 구분하지 않고 글자(준비·진행·완료)를 함께 쓴다.

## 글꼴

- 제목·숫자 라벨: IM Fell DW Pica (한글은 Noto Serif KR로 대체됨)
- 본문·입력: Noto Serif KR
- 수치·ID: IM Fell DW Pica에 `font-variant-numeric: tabular-nums`

크기: 캡션 12 / 본문 15 / 소제목 17 / 제목 22 / 현재 단계 22 / 화면 제목 36

## 터치와 손 조건

- 눌러야 하는 모든 요소는 44px 이상, 수행 모드 주요 버튼은 52px
- 체크 영역 36px, 현재 단계 44px. 체크 줄 전체를 누를 수 있게 한다.
- 수행 중 입력칸 높이 48px 이상
- 장갑 사용은 가정이므로 인터뷰 관찰(가정 3) 결과로 크기를 조정한다.

## 공통 컴포넌트

만들 순서는 Phase 2 → 3 순서와 같다.

- **Button**: primary(밀랍), ghost(종이). 높이 52, 두 줄 테두리 없음
- **StatusBadge**: 준비 / 진행 / 완료. 테두리 있는 도장 모양
- **StepRow**: 완료 / 현재 / 대기. 로마 숫자 번호, 현재 단계는 밀랍 도장 체크
- **NumberField (이름-값-단위 행)**: 이름, 값, 단위 선택, 삭제
- **ExperimentSummaryRow**: 제목, 프로젝트, 목적, 상태, 진행률, 주요 조건·결과, 편차, 수정일. 홈·프로젝트·실험 목록에서 정보 순서를 같게 한다.
- **ExperimentStartPicker**: 빈 실험 / 마지막 실험 / 기존 실험 선택과 이어받을 항목 미리보기
- **FilterBar**: 키워드, 칩(전체, 프로젝트, 상태, 기간), 정렬. 별도 검색 화면 없이 실험 목록에서 쓴다.
- **Toast**: 저장됨, 되돌리기(5초)
- **ConfirmDialog**: 삭제·덮어쓰기·완료 경고
- **EmptyState**: 실험 0건, 필터 결과 없음, 휴지통 비어 있음
- **SaveIndicator**: 저장됨 / 저장 중 / 저장 실패(다시 시도, 내보내기 안내)
- **AppShell**: 홈·프로젝트·실험·데이터 메뉴, 상단바(+ 새 실험, 설정), 하단 메뉴(좁은 화면)

## 반응형

- 1194px 이상(태블릿 가로, PC): 왼쪽 메뉴 96px + 본문
- 860px 이하: 메뉴를 하단으로, 수행 모드는 한 열로 쌓고 조건·결과 패널은 단계 목록 아래로
- 태블릿 세로(약 834px)는 좁은 화면 규칙을 따른다.
- 수행 모드는 항상 전체 화면, 나가기 버튼 하나만 둔다.
