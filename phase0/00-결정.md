# Phase 0 결정 기록

확정한 것과 아직 정하지 못한 것을 한 곳에 적습니다. 바꾸면 날짜와 이유를 아래에 덧붙입니다.

## 확정

- **코드명**: lablog (임시, 패키지 이름에만 사용)
- **첫 버전 범위**: s1 모으기 전체 + s2 찾기(분류·통합 검색). 첨부와 s3는 파일럿 이후.
- **저장**: 지금은 브라우저 로컬(IndexedDB)만. Supabase는 Phase 9.
- **스택**: Vite + React + TypeScript(strict) + React Router + Dexie + MiniSearch
- **테스트·품질**: Vitest + Testing Library + fake-indexeddb, oxlint, Prettier. E2E(Playwright)는 Phase 3에서 추가.
- **디자인 방향**: 엔틱 (바랜 종이 질감, 이중 테두리, 세리프 글꼴, 로마 숫자 단계, 붉은 밀랍 도장 현재 단계). 시안은 `../design-drafts.html`.
- **화면 크기 기준**: 태블릿 가로(1194×834)와 PC. 좁은 화면은 하단 메뉴로 전환.
- **저장소 구조 원칙**: 화면은 Repository 인터페이스만 부른다. ID는 UUID, 삭제는 소프트 삭제.

## 미정 (Phase 0 검증으로 결정)

- 수행 중 기기 입력이 가능한가 → `01-인터뷰-가이드.md`의 관찰 항목
- 사용 기기와 브라우저 범위 (예: 최신 Chrome/Edge, iPad Safari)
- 외부 클라우드 저장 허용 여부 (Phase 9 전제)
- 개인 노트 vs 팀 공유 중 우선순위

## 개발 환경

- Node.js LTS 24.20.0 (winget으로 설치), npm 11
- 이 PC의 터미널은 새로 열어야 `node` 경로가 잡힙니다. 열려 있는 터미널에서는 `C:\Program Files\nodejs`를 PATH에 추가해야 합니다.
- 프로젝트 위치: `lab/app`
- 자주 쓰는 명령
  - `npm run dev` 개발 서버
  - `npm run check` 린트 + 타입 검사 + 테스트
  - `npm run build` 배포용 빌드

## Git 규칙

- `main`은 항상 배포 가능한 상태로 둔다.
- 기능은 `feat/짧은-이름` 브랜치에서 작업하고 PR로 합친다.
- 커밋 메시지: `feat:`, `fix:`, `test:`, `docs:`, `chore:` 접두어 + 한 줄 요약.
- 비밀 값(`.env`)은 커밋하지 않는다. 형식은 `.env.example`에 둔다.
