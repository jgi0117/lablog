# 샘플 실험 기록 수집

목적: 테스트 데이터와 화면 설계에 쓸 실제 기록 3~5건을 모은다. 화면 문구, 단계 수, 조건 항목, 단위가 실제와 맞는지 확인하는 데 쓴다.

## 요청 문구 (연구원에게 보낼 내용)

"최근에 하신 실험 3~5건의 기록을 보여 주세요. 형식은 엑셀, 노트 사진, 메모 모두 괜찮습니다. 기밀이 될 수 있는 이름, 시약명, 수치는 가려도 됩니다. 구조(몇 단계인지, 어떤 항목을 적는지)를 알고 싶은 것입니다."

## 받고 싶은 것

- 절차 단계 목록 (단계 수, 문장 길이, 번호 매기는 방식)
- 조건 항목 (이름, 값, 단위 예시. 자주 쓰는 단위 목록)
- 결과 항목 (측정값, 그래프, 사진 등 형태)
- 변경·실패 기록이 있다면 어떻게 적혀 있는지
- 실험 이름 짓는 방식 (예: 날짜-시료-조건)
- 분야별 용어 (자동완성과 검색 설계에 사용)

## 정리 양식

샘플 한 건당:
- 코드 (S1, S2…) / 분야 / 단계 수 / 조건 항목 수 / 결과 항목 수
- 기록이 있던 위치 (노트, 엑셀, 메모 앱…)
- 실제 단계 문장 3개 (익명화)
- 자주 쓴 단위
- 설계에 반영할 점

## 사용처

- Phase 1: 와이어프레임의 예시 문구, 조건·결과 입력 행의 단위 목록
- Phase 3: 단계 붙여넣기 기능의 입력 형식 점검
- Phase 6: 현실 데이터 1세트를 테스트 데이터로 입력

## 주의

- 기밀 자료는 받지 않거나, 받더라도 익명화한 뒤 이 폴더에 둔다.
- 원본 파일은 저장소에 커밋하지 않는다.
