# 기준선 측정

도입 전 수치를 먼저 재 둬야 KR을 평가할 수 있습니다.

## KR1 기준선: 지난 실험 찾는 시간

**과제**: "6개월 전쯤 한 실험 중 80°C 조건이 들어간 것을 찾아서 그 조건을 읽어 주세요."
(참여자마다 실제로 한 실험으로 바꿔서 냅니다.)

측정 방법
- 시작: 과제를 말하는 순간 / 끝: 해당 조건을 소리 내어 읽는 순간
- 못 찾으면 3분에서 중단하고 "실패"로 기록
- 참여자 3~5명이 각자 2건씩

| 참여자 | 과제 | 소요 시간(초) | 성공 여부 | 사용한 도구·위치 |
|---|---|---|---|---|
| R1 | 1 | | | |
| R1 | 2 | | | |

정리
- 성공한 건의 평균과 중앙값, 실패율
- 목표(10초 이내 열기)와 비교

## KR2 기준선: 재실험 사유 분류

최근 3개월 안의 재실험 5건 이상을 모아서 사유를 나눕니다. (연구원에게 요청하거나 인터뷰 중 확인)

| # | 실험(익명) | 다시 한 이유 | 분류 |
|---|---|---|---|
| 1 | | | 단계 누락 / 조건 오기록 / 장비 / 시약 / 시료 / 기타 |

분류 기준
- **단계 누락**: 절차에 있는 단계를 빠뜨림
- **조건 오기록**: 조건 값을 틀리게 적었거나 못 찾아서 다르게 수행
- **장비·시약·시료**: 기록과 무관한 원인
- **기타**: 위에 없는 경우 (적어 둔다)

판정
- 단계 누락 + 조건 오기록이 전체의 절반 이상이면 우리 문제 정의가 맞다고 본다.
- 절반 미만이면 우선순위를 다시 논의한다. (편차 기록, 템플릿을 앞당길지, 장비·시약 이슈를 다룰지)

## 가드레일 기준선: 기록 입력 시간

- 실험 한 건(단계 10개 정도)을 지금 방식으로 기록하는 데 걸리는 시간(분)을 잰다. 실험 중 기록과 나중에 옮겨 적는 시간을 나눠서 적는다.
- 파일럿 후 같은 방식으로 다시 재서 늘지 않았는지 비교한다.

| 참여자 | 실험 중 기록(분) | 옮겨 적기(분) | 합계 |
|---|---|---|---|
